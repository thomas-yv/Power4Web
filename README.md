# Power4Web
Une implémentation web du jeu classique **Puissance 4 (Connect Four)**, développée avec **Go** pour le backend et **HTML** pour le frontend. Ce projet est une démonstration éducative de l'intégration de Go et du web, permettant de jouer en multijoueur directement dans le navigateur.

## Présentation du projet

- **Backend** : Serveur Go gérant la logique du jeu et les requêtes HTTP
- **Frontend** : Interface web interactive en HTML (et éventuellement CSS/JS)
- **Statut** : Projet en phase initiale #BETA (~19 commits, aucune version publiée)
- **Contributeurs** : [thomas-yv](https://github.com/thomas-yv), [Quentin272727](https://github.com/Quentin272727), [clement444](https://github.com/clement444)

## Installation et configuration

### Prérequis
- [Go 1.20+](https://go.dev/dl/) installé
- Git

### Étapes

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/votre-utilisateur/Power4Web.git
   cd Power4Web
   ```

2. **Installer les dépendances :**
   ```bash
   go mod download
   ```

2. **Installer les dépendances :**
   ```bash
   go run .
   ```

Le serveur démarrera par défaut sur http://localhost:8080.
